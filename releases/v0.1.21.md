The Controller Pak moves into the shared runtime, with N64Recomp-browser v0.257.0's renderer and runtime. Like v0.1.20 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `50558356b059ad3fbaf5fe95380512b9dceaaf52`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `Rayman2Recompiled-v0.1.21-windows-x64.zip` and run `Rayman2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Rayman2Recompiled-v0.1.21-linux-x64.tar.gz` and run `Rayman2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**Changed:**

- The Controller Pak your game saves to is now the runtime's own, the one the other recompilations of the project share. It is the same file as before, `saves/controllerpak_1.mpk`, so a save made with an earlier release loads as it did.

These come with N64Recomp-browser v0.257.0's renderer and runtime.
