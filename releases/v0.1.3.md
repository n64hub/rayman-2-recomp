An icon of its own. Like v0.1.2 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `50558356b059ad3fbaf5fe95380512b9dceaaf52`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `Rayman2Recompiled-v0.1.3-windows-x64.zip` and run `Rayman2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Rayman2Recompiled-v0.1.3-linux-x64.tar.gz` and run `Rayman2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**The icon:** a glowing winged orb in a misty night forest, drawn for the project (nothing in it comes from the game), in place of the "Rayman 2 Recompiled" text tile. It shows on the program in Explorer and the taskbar, on the game's window (on Linux too, where the window had no icon before) and beside the game in the launcher's menu.
