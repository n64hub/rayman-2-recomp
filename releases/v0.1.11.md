A fix in the shared renderer for parts of one object that flickered at high refresh rates. Like v0.1.10 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `50558356b059ad3fbaf5fe95380512b9dceaaf52`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `Rayman2Recompiled-v0.1.11-windows-x64.zip` and run `Rayman2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Rayman2Recompiled-v0.1.11-linux-x64.tar.gz` and run `Rayman2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**Fixed:** parts of one object drawn at one spot and only scaled apart no longer flicker or swap places at high refresh rates.
