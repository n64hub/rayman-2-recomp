An update of the shared renderer and runtime. Like v0.1.15 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `50558356b059ad3fbaf5fe95380512b9dceaaf52`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `Rayman2Recompiled-v0.1.16-windows-x64.zip` and run `Rayman2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Rayman2Recompiled-v0.1.16-linux-x64.tar.gz` and run `Rayman2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**Changed:** the renderer and runtime are updated to N64Recomp-browser v0.203.0's. A controller unplugged and plugged in again keeps its port, its player and its rumble; the window's last row of pixels is drawn; and when the renderer falls behind, the game waits for it 30 ms at a time, not 100. The scene transition's fix from v0.1.15 is carried over onto the new renderer.
