A cleaner scene transition in a wide window. Like v0.1.3 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `50558356b059ad3fbaf5fe95380512b9dceaaf52`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `Rayman2Recompiled-v0.1.4-windows-x64.zip` and run `Rayman2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Rayman2Recompiled-v0.1.4-linux-x64.tar.gz` and run `Rayman2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**The scene transition:** the black blotches that close over the picture between scenes now spread evenly across the whole wide window, a third wider at 16:9, as one picture. Before, the sides were blacked out by a mirrored copy of the middle, drawn a second time.

At Aspect Ratio Original the game looks as before.
