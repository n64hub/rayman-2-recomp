A fix for the title screen after a wait in the launcher. Like v0.1.5 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `50558356b059ad3fbaf5fe95380512b9dceaaf52`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `Rayman2Recompiled-v0.1.6-windows-x64.zip` and run `Rayman2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Rayman2Recompiled-v0.1.6-linux-x64.tar.gz` and run `Rayman2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**Fixed:** the time spent in the launcher before Start Game no longer reaches the game's clock. After a couple of minutes there, the title screen flashed by for a moment without its START prompt and went straight to an attract demo, and pressing Start then didn't reach the main menu. The game now counts its time from its own boot, as on a console, so the title stays up and Start opens the menu however long the launcher was open. Donald Duck: Goin' Quackers, built on the same engine, had the same bug.
