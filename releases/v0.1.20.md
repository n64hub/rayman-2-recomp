A note on the game's own checks before it closes, and more controllers mapped. Like v0.1.19 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `50558356b059ad3fbaf5fe95380512b9dceaaf52`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `Rayman2Recompiled-v0.1.20-windows-x64.zip` and run `Rayman2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Rayman2Recompiled-v0.1.20-linux-x64.tar.gz` and run `Rayman2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**New:**

- When the game stops at one of its own checks, it no longer closes without a word: a message box names the check and the level first. If you see one, please report it with those two lines and what you were doing, so the cause can be found.
- More controllers and adapters are mapped out of the box, from SDL's controller database: among them 8BitDo, Raphnet, Mayflash and Hyperkin N64 and GameCube adapters, and Nintendo Switch Online's GameCube and SNES controllers.
