A fix for a crash at boot. Like v0.1.6 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `50558356b059ad3fbaf5fe95380512b9dceaaf52`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `Rayman2Recompiled-v0.1.7-windows-x64.zip` and run `Rayman2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Rayman2Recompiled-v0.1.7-linux-x64.tar.gz` and run `Rayman2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**Fixed:** pressing Start while the game boots no longer crashes it. Start held as the game starts opens its Controller Pak manager, as on a console, and reading that screen's font crashed the program a few seconds in, so a player pressing Start to get past the logos could lose the game before the title screen.
