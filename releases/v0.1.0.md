The first release of Rayman 2: Recompiled for Windows and Linux: a native PC port of the N64 game made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `50558356b059ad3fbaf5fe95380512b9dceaaf52`). Other regions and revisions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `Rayman2Recompiled-v0.1.0-windows-x64.zip` and run `Rayman2Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `Rayman2Recompiled-v0.1.0-linux-x64.tar.gz` and run `Rayman2Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**What works:** the logos, the language menu and the intro story, from the pirate ship to the prison hold; a new game into the Woods of Light; every level of the game's table, each loaded and drawn; the pause menu with its Save, Load and Options pages, and the world map's save prompt. Sound (the game's own audio code, recompiled), the game's Controller Pak saves kept across restarts, and keyboard and gamepad input.

**Enhancements**, each an option on the settings menu's Graphics tab with an Original value that plays as the console does:

- High resolution at the window's size, with anti-aliasing
- Smooth motion at the display's refresh rate, blended between the game's frames
- Widescreen: in a window wider than 4:3 the world reaches the window's edges, and the menus stay in the middle 4:3
- Keyboard and gamepad controls, rebindable

**Not checked yet:** a whole playthrough from start to end (every level has been loaded, but not played through to its exit, so expect the odd thing drawn wrong or a spot that hangs; reports are welcome on the [issues page](https://github.com/n64hub/rayman-2-recomp/issues)), long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The [README](https://github.com/n64hub/rayman-2-recomp#readme) has how to build it yourself.
